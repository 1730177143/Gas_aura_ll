# UE 学习知识库（gas_aura_ll）

本项目专属、**跨对话持久化**的 UE 学习记录。仅适用于 `gas_aura_ll`，不跨项目。

## 文件导航

| 文件 | 内容 | 何时读 |
|---|---|---|
| [concepts.md](./concepts.md) | UE / GAS / CommonUI 等**概念与原理** | 问"这是什么 / 为什么 / 原理" |
| [tips.md](./tips.md) | **技巧与踩坑**（报错、坑、更优写法） | 问"怎么解决 / 报错 / 有没有更好的写法" |
| [conventions.md](./conventions.md) | 本项目的**规范**（命名、目录、代码风格） | **写或改代码之前** |
| [workflows.md](./workflows.md) | 可复用的**流程 / SOP** | 问"一步步怎么做" |

> AI 请**按需只读相关文件**，不要一次性把四个文件全部读入上下文。

## 记录格式

每条记录统一使用下面格式，便于检索与追加：

```markdown
## <标题>
- 结论：一句话说清
- 要点：
  - ...
- 出处：`Source/.../X.cpp:123` 或 https://...
- 日期：2026-09-11
```

## 维护约定

- **只追加，不覆盖**；发现旧内容有误时，修改结论并标注修订日期。
- 每条必须有**可核查的出处**，项目相关的优先写清文件路径（含行号更佳）。
- 分类拿不准时归入最接近的一类，不要新建零散文件。
- 同一主题内容变多时，可拆分独立文件，并在本页登记。
- 与 AI 协作：对话里说"记录到知识库"即可，AI 会按 `CODEBUDDY.md` 的规则追加。

## 与其它记录方式的区别

- `参考.md`（项目根目录）：个人零散草稿，已被 `.gitignore` 忽略，**不进**本知识库。
- 本知识库：结构化、可检索、值得长期保留的项目知识。
